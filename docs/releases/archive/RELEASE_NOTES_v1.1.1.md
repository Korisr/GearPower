# GearPower v1.1.1

任务栏电量条修复版。

## 修复

- 全屏应用（包括无边框全屏、游戏、视频）时自动隐藏任务栏电量条
- 切换窗口或点击任务栏时重新置顶，解决电量条短暂消失再出现
- 增加 450ms 隐藏防抖，避免任务栏动画造成闪烁
- 前台窗口变化时立即重新检测，而不是等待 3 秒轮询
- 托盘图标和任务栏优先显示未充电设备，充电中的低电量设备不再抢占置顶
